# SmartCheck iPhone Web Diagnostics (GitHub Pages)

## วิธีเปิดใช้งานฟรีบน GitHub Pages (3 ขั้นตอน)
1. สร้าง Repository ใหม่บน GitHub (ตั้งเป็น **Public**) เช่น `smartcheck-web`
2. กด `uploading an existing file` แล้วลากไฟล์ `index.html` ลงไป → กด **Commit changes**
3. ไปที่ **Settings → Pages** → ช่อง Branch เลือก **main** → กด **Save**
4. รอ 1–2 นาที แล้วเปิดลิงก์ `https://<username>.github.io/smartcheck-web/` ใน Safari บน iPhone ได้ทันที
